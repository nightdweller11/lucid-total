# Lucid Total

**The operating system of an AI-run company.** One living map of everything the company intends, does, decides and learns; an embedded AI that knows all of it, answers, acts, moves the work and, over time, runs the company's processes. Built first to run Lucid (the makers of Lucid Chat), designed to run any company.
